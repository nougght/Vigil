
# repository

## Основные принципы repository слоя

### Использование транзакции

Чтобы можно было использовать и транзакцию и обычное подключение, используется интерфейс, т.к. `pgx.Conn`, `pgxpool.Pool`, `pgx.Tx` имеют одинаковые сигнатуры методов.

Для выполнения запросов используется или транзакция из контекста, или подключение, имеющееся в репозитории.

### Использование pgx методов

#### pgx.Exec

Используется при отсутствии возвращаемых значений, часто с проверкой `RowsAffected()`.

#### pgx.Query

Можно использовать совместно с методами:

- `pgx.CollectOneRows` - скан первого элемента в структуру с закрытием `pgx.Rows`(последовательный перебор невозможен), при отсутствии элементов возвращает ErrNoRows
- `pgx.ColectExactlyOneRow` - то же самое, что и предыдущий метод, но если элементов более 1, то возвращается ошибка ErrTooManyRows
- `pgx.CollectRows` - скан элементов в срез структур

#### pgx.QueryRow

Возвращает `pgx.Row`, удобно использовать для сканирования одиночных полей через `.Scan(&name)`.
